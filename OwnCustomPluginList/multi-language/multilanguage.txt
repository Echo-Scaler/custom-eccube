### ၁။ Plugin ကို စတင်ဖွင့်လှစ်ခြင်း (Activation)

Plugin အား စနစ်ထဲတွင် အောင်မြင်စွာ တပ်ဆင်ပြီး (Install/Enable) ပြုလုပ်ပြီးဖြစ်ပါသည်-
```bash
docker compose exec ec-cube bin/console eccube:plugin:install --code=MultiLanguage
docker compose exec ec-cube bin/console eccube:plugin:enable --code=MultiLanguage
docker compose exec ec-cube bin/console cache:clear
```

### ၂။ Frontend (Customer/ဝယ်ယူသူများ) အတွက် အသုံးပြုပုံ

Frontend တွင် ဘာသာစကား ပြောင်းလဲအသုံးပြုနိုင်ရန် နည်းလမ်း (၃) မျိုး ရှိပါသည်-

#### နည်းလမ်း (၁) - Header ရှိ Language Switcher Dropdown မှ ပြောင်းလဲခြင်း (အလွယ်ကူဆုံး)
*   Website ၏ ညာဘက်အပေါ် Header နေရာတွင် **Language Switcher Dropdown** ခလုတ် ပေါ်နေပါမည်။
*   ထိုခလုတ်ကို နှိပ်လိုက်ပါက ရွေးချယ်နိုင်သော ဘာသာစကားစာရင်း ပေါ်လာပါမည်-
    *   🇯🇵 **日本語 (Japanese)**
    *   🇬🇧 **English**
    *   🇲🇲 **မြန်မာ (Burmese)**
*   မိမိနှစ်သက်ရာ ဘာသာစကားကို နှိပ်လိုက်သည်နှင့် စာမျက်နှာတစ်ခုလုံး (Navigation, Cart, Login, Buttons, Messages) သည် ရွေးချယ်လိုက်သော ဘာသာစကားသို့ ချက်ချင်း ပြောင်းလဲသွားပါမည်။

#### နည်းလမ်း (၂) - URL Query Parameter ဖြင့် ပြောင်းလဲခြင်း
*   URL ၏ အဆုံးတွင် `?_locale=my` (သို့မဟုတ် `?_locale=en`, `?_locale=ja`) ဟု ရိုက်ထည့်၍ တိုက်ရိုက် ဝင်ရောက်နိုင်ပါသည်-
    *   မြန်မာဘာသာ: `http://localhost:8080/?_locale=my`
    *   အင်္ဂလိပ်ဘာသာ: `http://localhost:8080/?_locale=en`
    *   ဂျပန်ဘာသာ: `http://localhost:8080/?_locale=ja`
*   ဤနည်းလမ်းသည် Social Media သို့မဟုတ် Email များတွင် ဘာသာစကားအလိုက် Link များ မျှဝေရာတွင် အထူးအသုံးဝင်ပါသည်။

#### နည်းလမ်း (၃) - Session မှ အလိုအလျောက် မှတ်သားထားခြင်း (Persistence)
*   ဝယ်ယူသူက ဘာသာစကား တစ်ကြိမ် ရွေးချယ်ပြီးသွားပါက Browser Session ထဲတွင် အလိုအလျောက် မှတ်သားထားမည် ဖြစ်သောကြောင့် အခြား Product စာမျက်နှာများ၊ Cart သို့မဟုတ် Checkout စာမျက်နှာများသို့ သွားရောက်သော်လည်း ရွေးထားသော ဘာသာစကားအတိုင်း ဆက်လက်ပြသနေမည် ဖြစ်ပါသည်။

> [!TIP]
> မြန်မာဘာသာစကား ရွေးချယ်ထားချိန်တွင် ဖောင့်မကွဲစေရန်နှင့် စာလုံးပေါင်းသန့်ရှင်းစေရန် **Google Fonts (Noto Sans Myanmar)** ကို အလိုအလျောက် ချိတ်ဆက် load လုပ်ပေးထားပါသည်။

### ၃။ Backend / Admin Panel (စီမံခန့်ခွဲသူများ) အတွက် အသုံးပြုပုံ

Admin Panel မှနေ၍ ဆိုင်တွင် အသုံးပြုမည့် ဘာသာစကား စနစ်များကို စီမံခန့်ခွဲနိုင်ပါသည်-

#### အဆင့် (၁) - Setting စာမျက်နှာသို့ သွားရောက်ခြင်း
1.  Admin Panel (`http://localhost:8080/admin/`) သို့ ဝင်ရောက်ပါ။
2.  ဘယ်ဘက် Sidebar Menu မှ **設定 (Settings)** > **店舗設定 (Shop Settings)** > **多言語設定 (Multi-Language Settings)** သို့ သွားပါ။
    *(သို့မဟုတ် URL: `http://localhost:8080/admin/multi_language/config` သို့ တိုက်ရိုက်သွားနိုင်ပါသည်)*

#### အဆင့် (၂) - ပြင်ဆင်နိုင်သော Feature များ
*   **Default Language (မူလဘာသာစကား):**
    *   ဆိုင်သို့ ပထမဆုံး ဝင်ရောက်လာသော User တိုင်းကို မည်သည့်ဘာသာစကားဖြင့် စတင်ပြသမလဲ ရွေးချယ်နိုင်ပါသည် (ဥပမာ- `ja`, `en`, သို့မဟုတ် `my`)။
*   **Enabled Languages (အသုံးပြုခွင့်ပြုမည့် ဘာသာစကားများ):**
    *   Frontend တွင် ပြသပေးလိုသော ဘာသာစကားများကို Checkbox ပေး၍ ဖွင့်/ပိတ် ပြုလုပ်နိုင်ပါသည်။ (ဥပမာ- English နှင့် မြန်မာ နှစ်မျိုးတည်းသာ ဖွင့်ထားလိုပါက ဂျပန်ဘာသာစကားကို အမှန်ခြစ် ဖြုတ်ထားနိုင်ပါသည်)။
*   **Auto-Detect Language (စက်၏ ဘာသာစကားအလိုက် အလိုအလျောက် ပြောင်းလဲပေးခြင်း):**
    *   User အသုံးပြုနေသော ဖုန်း/ကွန်ပျူတာ၏ Browser Language ကို ဖတ်ပြီး သင့်တော်သော ဘာသာစကားသို့ အလိုအလျောက် ပြောင်းပေးမည့် စနစ်ကို Enable/Disable ပြုလုပ်နိုင်ပါသည်။
3.  ပြင်ဆင်ပြီးပါက **登録 (Save Settings)** ခလုတ်ကို နှိပ်၍ သိမ်းဆည်းပါ။

### ၄။ Developer များအတွက် Code ထဲတွင် အသုံးပြုပုံ

#### (က) Twig Template ထဲတွင် စာသားများ ဘာသာပြန်ခြင်း
Frontend twig ဖိုင်များထဲတွင် ဘာသာစကားအလိုက် စာသားပြောင်းလိုပါက Symfony ၏ `|trans` filter ကို အသုံးပြုနိုင်ပါသည်-
```twig
{# Core EC-CUBE translation keys #}
<p>{{ 'common.cart'|trans }}</p>
<button>{{ 'common.login'|trans }}</button>
```

#### (ခ) Controller (PHP) ထဲတွင် ဘာသာပြန်ခြင်း
PHP Code ထဲတွင် Message များ ဘာသာပြန်လိုပါက `TranslatorInterface` ကို Inject လုပ်၍ အသုံးပြုနိုင်ပါသည်-
```php
use Symfony\Contracts\Translation\TranslatorInterface;

public function someAction(TranslatorInterface $translator)
{
    $message = $translator->trans('front.cart.empty');
}
```
