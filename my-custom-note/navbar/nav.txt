# Redesign Navigation Bar UI (Shopcart Style)

This plan details the redesign of EC-CUBE's storefront navigation and header UI to match the modern "Shopcart" design provided in the user's screenshot.

## Proposed Design Overview

The new navigation header consists of two clean, modern tiers:

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│ 📞 +001234567890       Get 50% Off on Selected Items | Shop Now          Eng ∨   Location ∨ │ (Top Bar - Deep Green)
├─────────────────────────────────────────────────────────────────────────────────────────────┤
│ 🛒 Shopcart   Categories ∨   Deals   What's New   Delivery   [🔍 Search Product]   👤 Account  🛒 Cart  │ (Main Nav - White)
└─────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. Top Announcement & Utility Bar (Forest Green `#003d29`)
- **Left**: Phone contact (`+001234567890` with phone icon).
- **Center**: Promotional banner (`Get 50% Off on Selected Items | Shop Now` linking to product catalog/sale).
- **Right**:
  - **Language Selector** (`Eng ∨`) with dropdown to switch between English (`en`), Japanese (`ja`), and Burmese (`my`).
  - **Location Selector** (`Location ∨`) with dropdown to select region/country.

### 2. Main Navigation Bar (Clean White `#ffffff` with subtle elevation)
- **Left (Logo)**:
  - Custom SVG vector logo (green shopping cart with fresh orange fruit/carrot and vibrant green leaves).
  - Brand name **Shopcart** in bold modern typography.
- **Center-Left (Navigation Links)**:
  - **Categories ∨**: Dropdown menu showing dynamic categories from EC-CUBE database with smooth animations.
  - **Deals**: Direct link to discounted products / catalog.
  - **What's New**: Direct link to new arrivals (`/products/list?orderby=1`).
  - **Delivery**: Direct link to delivery information / user guide.
- **Center-Right (Search Bar)**:
  - Pill-shaped input with light gray background (`#f3f4f6`) and smooth focus states.
  - Placeholder: `"Search Product"`.
  - Search magnifying glass icon button submitting directly to `/products/list?name=...`.
- **Right (User Utilities)**:
  - **Account**: User outline icon + "Account" label with interactive dropdown for Login, Register, My Page, and Logout.
  - **Cart**: Shopping cart icon + floating count badge + "Cart" label with hover/click mini-cart summary and link to `/cart`.

### 3. Mobile & Tablet Responsiveness
- Collapses into a compact top bar and header with hamburger menu (`fas fa-bars`), logo, search toggle, account icon, and cart icon with badge.
- Slide-out drawer menu with accordion categories and quick navigation links.
